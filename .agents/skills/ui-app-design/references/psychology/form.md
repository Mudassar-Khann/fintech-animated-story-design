# Form & Input Psychology

### Error Anxiety Reduction
- Provide inline validation rather than waiting for form submission.
- Use success states (green checkmarks) immediately upon valid input to provide micro-rewards.
- Label everything clearly; avoid relying solely on placeholders which disappear on focus.
